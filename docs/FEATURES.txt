LIVE - IN THE BUILD, VERIFIED
==============================================================================
Verified by: node tests/manual.js (all pass), AUTOTOOLS=1 node tests/corpus.js
(2,495 / 2,806 real CAM programs clean), .tools/qa/qa.mjs (51 / 52 Playwright
checks pass; the 1 failure is a stale test expectation, not a product bug -
see BUGS below).

INTERPRETER (core.js):
  - Klartext parser/interpreter: L/C/CC/CR/CP/LP moves, RL/RR as real offset
    paths (not centreline), RND, CHF, CT, APPR/DEP, ZX/YZ plane arcs.
  - Q-parameter formulas FN 0-FN 19, jumps (FN 9, CALL LBL n REP), REP Q.
  - Cycles: 1, 2, 4, 17, 18 (old-style); 7, 8, 9, 10, 11, 32, 247 (non-motion:
    datum shift, mirror, rotation, scaling, tolerance, datum point); 200-215
    (drilling/reaming/boring/tapping/slots); 220/221 (patterns); 230/231
    (surface milling).
  - M3/M4/M5/M8/M9/M2/M30, M99 blockwise cycle call, correct block-start vs
    block-end M-function timing, tool table via TOOL CALL, TNC-style error
    register.
  - F AUTO approximated as the TOOL CALL block's F (the real control reads a
    cutting-data table the simulator doesn't have - documented simplification).
  - Tools missing from the table are auto-created on program upload/import,
    matching import behaviour on a real control.

SIMULATOR:
  - Height-field material removal: the tool stamps its real radius along
    every feed move; scrubbing backwards rebuilds the blank; removed volume
    integrated from the height field. Vertical tool axis only - no undercuts,
    no 5-axis yet.
  - Four operating modes as on the control, each with its own soft-key row;
    run comparison (reference A vs. current run: cycle time, feed/rapid path,
    moves, min Z, volume).
  - sim.js: shared timing/arc tessellation and a safety analysis (rapid into
    material, cutting with spindle stopped, tool below the blank, chip load).

MATERIALS AND LOOK (materials.js, look.js):
  - Alloy presets (aluminium, titanium, steel, stainless, brass, cast iron)
    and industry presets (turbine, aerospace, ground finish, cast): color,
    metalness, roughness, chip/spark color, with a picker.
  - RoomEnvironment via PMREMGenerator for metal reflections, ACES filmic
    tone mapping, FXAA through EffectComposer - all wired through the
    TNC_UI plugin bus's ui.render hook.

THREE.JS UPGRADE:
  - r128 -> r186, bundled with its addons and the three.quarks particle
    library by esbuild (vendor/three-entry.mjs) into one classic script
    (window.THREE, window.QUARKS). ColorManagement kept disabled to preserve
    the existing r128-style colour look.
  - window.QUARKS is in the page but not yet used by fx.js - see IN
    PROGRESS below.

PROFILES AND PROGRAM I/O (profile.js, ui.js):
  - One personal profile per browser (IndexedDB via idb-keyval), autosave,
    name prompt on first visit, wipe/reset.
  - Export/import profile as .zip with a Merge/Replace choice on import.
    Per-machine tool table, import/export as TOOL.T.
  - Load .H/.I (UTF-8 or Windows-1252), .zip of programs, drag-and-drop.
    Save as .H with Ctrl+S in numbered TNC listing format (CRLF).
  - PGM MGT program manager, block editor, undo/redo (Ctrl+Z /
    Ctrl+Shift+Z), boot splash, mobile layout.
  - window.TNC_UI plugin bus (scene/tool/tick/crash/resize, ui.render) that
    fx.js, look.js and materials.js attach to.

AI PROGRAM GENERATION (ai.js):
  - OpenRouter only, BYOK - never Anthropic direct (checked: no Anthropic
    endpoint string anywhere in the built page).
  - Default model deepseek/deepseek-v4.1-flash (checked against OpenRouter's
    model list 2026-09-27: $0.035/M in, $0.29/M out - prices move, recheck
    periodically).
  - One repair pass: compile the AI's program, feed errors back. Prompt
    includes the operator's own tool table.
  - Key in sessionStorage/localStorage, never a cookie.
  - Tested so far only against a mocked OpenRouter (QA suite). No run
    against the real API in this repo yet.

TEACHING (lessons.js):
  - LEARN lessons, BREAK IT (famous ways to wreck a machine, each with the
    fix), a power-user manual, and the AI system prompt.

TOOLS, CALLOUTS, FLOW (tools3d.js, callouts.js, flow.js):
  - Real tool geometries in their holders.
  - View-aligned leader-line callouts (TOOL, TOOL HOLDER, PART).
  - Program-as-flowchart alternative view.

EFFECTS (fx.js):
  - Chips that land on the part, sparks, coolant spray on M8, smoke and
    fire (toggle, off by default), crash burst.

PROGRAMS (selector in the Program header, NAMEPLATE.H opens first):
  - NAMEPLATE.H - V1 garage plate 300 x 200 x 20: chamfered letters with
    T9, 1 x 45 edge break with T8, four mounting holes with CYCL 200.
  - NAMEPLATE_V2.H - 220 x 60 x 10: letters with real CC/C and CR arcs.
  - BRACKET.H - the teaching program: LBL/REP, FN formulas, arcs, CYCL 200.

BUILD:
  - build.py is fully data-driven: LIBS (JSZip, idb-keyval), MODULES
    (project .js files, ui.js last), TEXTS (this file, history.txt,
    RELEASES.txt/ROADMAP.txt when they exist -> window.TNC_* globals for
    this DEV modal). A new module is one line.

IN PROGRESS - NOT YET DONE
==============================================================================
  - SPINDLE ? false alarms: ~399 real-world programs trip the tapping
    cycles' spindle-direction check (cycleTap in core.js). Under
    investigation - see TODO.md.
  - fx.js does not yet use three.quarks, even though it is bundled into the
    page. Chips/sparks/coolant still run on the pre-upgrade approach.
  - Cycles 3, 5, 12, 13, 14/20-25, 19, 26, 27/28 not implemented.
  - TCH PROBE touch-probe cycles not implemented - confirmed not in the
    426/430 manual (iTNC 530/TNC 640 dialect); real CAM programs that call
    them are correctly rejected, not a bug.
  - FK (free contour programming) not implemented.
  - RELEASES.txt does not exist yet, so the DEV modal's third tab (which
    build.py already wires up) is empty.
  - Live visual translation: cursor-on-a-block driving the flow view with
    an animated tool trace. Both halves exist (traceFor/traceTick in
    ui.js, pathSVG in flow.js) and have never been connected.
  - TNC 430 multi-axis: research only, no code. Needs the user's machine
    layout before starting.
